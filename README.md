# 🛡️ Network Intrusion Detection Dashboard

A real-time Network Intrusion Detection Dashboard developed using Python, Flask, Scapy, Wireshark, and Scikit-learn to monitor network traffic, detect suspicious activities, and visualize network statistics.

---

## 📌 Features

- Capture live network packets using Scapy
- Monitor network traffic in real time
- Detect suspicious packets using machine learning
- Generate intrusion alerts
- Visualize packet statistics with interactive charts
- Display protocol-wise traffic analysis
